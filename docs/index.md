# FiberVent

FiberVent is computer code that simulates a left ventricle pumping blood around a systemic circulation. The ventricle is mimicked using the single fiber approach developed by Arts and co-authors. Myofibril-level contraction is simulated using [FiberSim](https://www.campbell-muscle-lab.github.io/FiberSim). Arterial blood pressure is regulated by an [in_silico_baroreflex](link to Sharifi et al)
