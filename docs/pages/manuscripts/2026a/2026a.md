# 2026a

## Overview

This page explains how to reproduce the simulations and figures that were submitted to BioRxiv in May 2026.

## Instructions

Import notes
{: .label .label-blue}

* FiberVent will <i>only</i> run on Windows PCs. 
* Each simulation will take several hours to run on a single thread
* Some figures show simulations collated from hundreds of simulations. The complete set of simulations may take more than a week to complete on a laptop.

<hr>

## Setup 

+ Clone the [FiberVent repo](https://link) to a local directory that will be referred to as `<repo>`
+ Install [Conda](link) if not already available
+ Install the FiberVent environment if not already available
  + opening a terminal and changing the directory to `<repo>/code/FiberVentPy/environment`
  + run `conda env create environment.yml`
+ Activate the conda environment with the command `conda activate FiberVent`
+ Change the working directory to `<repo>/code/FiberVentPy/FiberVentPy`

## Run simulations

These steps may take hours
{: .label .label-blue}

These commands will run the simulations from which the figures are derived.

+ Generate the hundreds of simulations summarized in Figures 3
  + Run the command `command`

## Create figures

The published figures can be recreated using MATLAB scripts.

+ Clone the [TCVR_utilities](repo) to a local directory that will be referred to as `<TCVR_repo>`
+ Start MATLAB
+ Add `<TCVR_repo>/code` and its subfolders to the MATLAB path
+ Simulation time-course figures
  + Run `<repo>/manuscripts/2026a/MATLAB_code/figure_simulation_time_courses.m`
+ Summaries of growth
  + Parse simulation files to collate summary data
    + Run `<repo>/manuscripts/2026a/MATLAB_code/blah`
  + Generate figures
    + Run `<repo>/manuscripts/2026a/MATLAB_code/figure_xy.m`
